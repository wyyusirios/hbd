# PROJECT: YOU

Пиксельная point-and-click RPG на день рождения Артёма: пролог, 23 уровня, HOME FOUND, финал и галерея воспоминаний.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Деплой на Vercel

Вариант 1, через CLI:

```bash
npx vercel
```

Вариант 2: залить папку `project-you` в GitHub-репозиторий и импортировать его на vercel.com/new. Настройки по умолчанию подходят, Framework Preset определится как Next.js.

## Проверка

- `?debug=1` в адресе (например `http://localhost:3000/?debug=1`) добавляет в меню (≡) выпадающий список «перейти к» для прыжка на любой уровень. Предметы с предыдущих уровней выдаются автоматически.
- Прогресс хранится в `localStorage` браузера. Сбросить его можно через меню → «Начать заново».

## Устройство

- `src/game/data.ts`: порядок сцен, награды, тексты предметов.
- `src/game/scenes/*`: пролог, главы I–V, галерея.
- `src/game/pixel/sprites.ts`: спрайты (сетки символов и векторные формы для ласточки).
- `src/game/pixel/backgrounds.ts`: процедурные фоны 320×180.
- `public/img/`: две готовые иллюстрации (город и комната).
